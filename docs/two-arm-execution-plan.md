# Two-arm paper: active framing and execution plan

Reframed 2026-09-20. This plan supersedes the earlier visibility-gradient and
coverage-prediction-led paper plans. It records implemented work separately from
new evidence that still has to be collected. A passing software test is not a
validated research result. Non-human follow-up execution is recorded in
[the latest progress report](../analysis/nonhuman_progress/README.md).

## 1. One paper, one shared evidence foundation

**Working title:** *Measuring Cross-Layer Crypto Censorship: Enforcement Evidence
and Observation Limits*.

**Central question:** How reliably can public evidence characterize cross-layer
execution and reversal of crypto restrictions when observation is incomplete?

| Research question | Arm | Required output |
| --- | --- | --- |
| RQ1: Who restricts what, on which surface, and how does restriction/recovery unfold? | Domain empirical research | Supported action stages and bounded behavior/timing summaries |
| RQ2: What can each evidence channel observe, and where does it fail? | Measurement research | Coverage, source-support errors, scoped-negative validity, and cost |
| RQ3: Which RQ1 conclusions survive evidence and measurement correction? | Joint evaluation | Same-unit before/after comparisons with uncertainty and explicit missingness |

The historical registry and the bounded validation cohort serve **both arms**.
They are not themselves the two arms. A measurement correction must feed an
actual domain comparison; a domain pattern must state the evidence and population
scope under which it is supported.

The working artifacts now include the corpus, diagnostic audit, completed
candidate endpoint campaign and bounded historical-interface comparison.
The joint evaluation remains proposed: these provisional cohort measurements
do not establish human eligibility, full-window event labels or independent
reference judgments.

| T6 | Run both arms and joint comparisons — analysis scripts plus author interpretation | Evaluate legacy, revised and explicit naive baseline on the same independently assessed units; compare coverage/error/cost; report supported behavior, timing and recovery; show changes and robust conclusions, with clustered uncertainty | T1, T2 and T5 |
| T7 | Submission package — authors | Replace pending text with supported results; validate references and venue rules; all applicable release checks pass; freeze reproducible archival snapshot and obtain actual author sign-off | T6 |

No identity, signature, human rating, source retrieval, query result or release
approval may be synthesized to close a task. An unavailable historical observation
is a legitimate gap, not an instruction to invent or impute a response.

T2 needs care: the legacy admitted-event schema restricts missing observations.
A sidecar adjudication table can preserve gaps immediately; changing the schema
and migration policy requires a coherent versioned change. Dropping troublesome
records only to make a readiness check green would change the study denominator.

## 4. Concrete work packets

**Retrospective audit (E1).** Run `make measurement-audit`. Coordinator materials
and blank sheets are in `analysis/measurement_audit/`. Distribute only the
reviewer packet and raw evidence, not `sealed_key.csv` or flag queues. The key is
plain text, so its filename provides no access control. Existing
`analysis/inter_rater_human_full/` is preserved; it is not substituted for these
blank independent materials. If a sample replaces the prepared census, record
inclusion probabilities and keep a uniform random component.

**Bounded cohort (E2).** Run `make validation-cohort-preflight`. This reads local
OFAC recent-action captures and prepares source inventories, calendar ledgers,
unadjudicated address candidates, the proposed panel and blank work logs.
An uncached day is unassessed, not a day with no action. An Ethereum-shaped string
is a candidate, not an adjudicated designation target. No outcome is measured by
this command. See [the protocol](two-arm-validation-protocol.md) before T3–T5.

**Joint result table.** T6 must report each substantive claim with its original
scope, corrected scope, eligible/observed denominator, legacy estimate, validated
estimate or bound, and reason for any change. A disappeared pattern is informative
only when the correction and its reference evidence can be audited. The designed
panel is not a representative six-layer sample.

## 6. Submission positioning after evidence completion

Keep both arms in one paper. An IMC-oriented version should lead with an evaluated
measurement problem and demonstrate how its solution changes domain inference.
A domain-oriented version should lead with validated restriction/recovery findings
and use the measurement arm to establish their limits. The underlying data and
joint experiments stay the same. Select the venue after T6 establishes the
strongest contribution; current venue deadlines and formatting must be checked
when preparing an actual submission. This plan makes no acceptance prediction.
