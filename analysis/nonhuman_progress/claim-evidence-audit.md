# Claim--evidence audit for the two-arm paper

Audit date: 2026-09-20. This audit covers the current machine artifacts and the
claims they could support in the paper. It does not adjudicate source semantics,
approve a submission or substitute machine labels for independent human review.
The collection counts agree with the offline validation-progress summary,
schema `1.1.0`; repeated retrieval stages concern the same selected OONI
records and must not be added as independent observations.

Status meanings:

- **Supported (bounded):** the artifact directly supports the stated result at
  its declared population, time and transport scope.
- **Qualified:** a narrower observation is supported, but the natural broader
  wording would exceed the evidence.
- **Pending:** the required independent or raw evidence does not yet exist.
- **Unsupported:** the available artifacts cannot establish the claim; do not
  state it as a result.

## Cross-arm claim rule

Each domain-arm result should carry four fields into the joint table: the source
frame, eligible denominator, observed denominator and evidence channel. Each
measurement-arm result should state which domain inference changes after the
correction. Until independent references exist, the current paper can report
executed bounded observations and measurement failure modes; it cannot report a
validated correction effect.

The strongest currently supportable joint statement is: within a machine-frozen
OFAC-derived cohort, 49 of 70 issuer units have matching records in the declared
indexed event streams, while exact timing, causal attribution, independent chain
completeness, public-disclosure observability and independent human validity
remain separately bounded. This is an observed evidence pattern, not an
enforcement-effect estimate.
